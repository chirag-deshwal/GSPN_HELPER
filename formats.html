💡 Pro-Tips for Copy-Pasting

  • Direct Paste: You can directly select the table rows on the GSPN web page with your mouse, press Ctrl+C, and paste into the text area with Ctrl+V.
  • HTML or Plain Text: Both are auto-detected. Whether you copy rendered text or right-click "View Selection Source" HTML, the parser will extract all fields cleanly.
  • Auto-Product Category: The tool automatically infers the product category (WM, REF, RAC, TV, MWO) based on Samsung model code prefixes.
