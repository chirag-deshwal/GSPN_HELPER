GGN Standard Template Context & Dictionary

Detailed rules, data sources, and formatting specifications for all 28 GGN Standard columns.

📌 Key GGN Standard Rules & Updates

  • DATE: Always populated with today's execution date formatted strictly as mm/DD/yyyy (e.g. 09/10/2026).
  • SVC (Service Center Name): Represents the Service Center Name. If there is no service center name data present, it is kept strictly empty (""). Numeric 10-digit Call IDs / ASC Job Numbers are never placed into SVC.
  • No. (Row Index): Sequential 1-based index (1, 2, 3...) functioning as the row sequence number (SR. NO.).
  • Service Order No. (Call ID): Guaranteed 10-digit Call ID starting with 4******* (e.g. 4441809308), extracted from Management Lite or Print Command, with fallback to ASC Job No (ASC_JOB_NO). Never blank when Call ID data is present.
  • Reason (GSPN): Strictly populated from Management Lite row 2. It will never be overwritten by Step 1 Print Command's remarks.
  • REDO: 28th column located at the end of the template, populated from Management Lite row 1 (e.g. Y or N).
  • Enforced Blank Fields: Remarks, Sub Remarks, Pending At, and Pending Reason are strictly blank ("").

GGN Standard Column Dictionary (28 Columns)

Exact order and mapping specifications for preview and Excel export.

# Column Header Data Source Format / Behavior / Example
1 Date Today's Date Formatted as mm/DD/yyyy (e.g. 09/10/2026).
2 SVC Service Center Service center name. If no service center name data, left strictly empty "".
3 No. Row Index Row sequence number 1, 2, 3... (acts as SR. NO.). Centered in Excel.
4 Service Order No. Management Lite / PC 10-digit Call ID starting with 4******* (e.g. 4441809308), fallback to ASC Job No.

6 Aging Calculated Days since assignment: =TODAY() - Assigned Date. Includes Excel x:f formula.
7 TAT Extension IFS Color-coded range (0–2 Days green, 3–7 Days yellow, etc.) with Excel x:f IFS formula.
8 Model Name Print / ML Device model code (e.g. WA80F08S2CTL, RT28T3742S8).
9 Product 15-Branch IF Categorized product (HHP, AC, AUD, AV, IT, MW, REF, WM, DW, Other).
10 WIFI ML / PC WIFI feature indicator (or blank if not present).
11 Engineer Print Command Assigned service technician name (e.g. Santosh Sah).
12 TL Name Print Command Team Leader name (if available).
13 Telephone (Mobile) Print Command Customer mobile number formatted as text (mso-number-format: \@).
14 Remarks Enforced Blank Strictly empty string "".
15 Sub Remarks Enforced Blank Strictly empty string "".
16 Address Print Command Customer service address.
17 SR. Management Lite Product Serial Number / IMEI (e.g. 0000, M000).
18 Wty Status Management Lite Warranty status (e.g. In Warranty, Out of Warranty).
19 Customer Name Management Lite / PC Customer's full name (e.g. Pankaj Ahlawat).
20 App Date Management Lite / PC Appointment date (e.g. 05.09.2026).
21 App Time Management Lite / PC Appointment time (e.g. 12:00:00).
22 Service Type (Status) Management Lite / PC Expanded service type (e.g. IN-HOME, Initial Installation, Stock Repair).
23 Status (GSPN) Management Lite GSPN status from Management Lite (e.g. Engineer Assigned).
24 Reason (GSPN) Management Lite GSPN reason strictly from Management Lite row 2. Protected against remark overwrites.
25 Pending At Enforced Blank Strictly empty string "".
26 Pending Reason Enforced Blank Strictly empty string "".
27 1st Service Comment Print Command First call confirmation / comment from Step 1 Print Command.
28 REDO Management Lite REDO flag from Management Lite row 1 (Y or N).
